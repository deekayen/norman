Norman is the best way to touch type

Norman is a fully optimized alternative keyboard layout to QWERTY for touch typing in English. It maintains keyboard shortcuts for the letters QWASZXCV and keeps 22/26 letters in the normal use pattern of their QWERTY finger, if not the original QWERTY location. I think it's all-around better than Colemak, Minimak, Workman, Qwpr, Dvorak, Asset, and Colman, easier to learn, and just as efficient, if not more so. I'm so confident in this claim, I've even made an installer for Mac with Norman which includes those other layouts.

Downloads
